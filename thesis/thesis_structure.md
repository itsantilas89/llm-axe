# Αναλυτική Δομή Διπλωματικής

Προτεινόμενος στόχος έκτασης: 90-120 σελίδες μαζί με βιβλιογραφία και
παραρτήματα.

## 0. Προκαταρκτικά

Ενότητες:
- Εξώφυλλο σύμφωνα με Οδηγό Συγγραφής ΣΗΜΜΥ ΕΜΠ.
- Σελίδα έγκρισης / τριμελής επιτροπή.
- Copyright.
- Περίληψη στα ελληνικά.
- Λέξεις-κλειδιά.
- Abstract στα αγγλικά.
- Keywords.
- Ευχαριστίες.
- Πίνακας περιεχομένων.
- Ευρετήριο σχημάτων.
- Ευρετήριο πινάκων.

Στόχος: 8-12 σελίδες.

## 1. Εισαγωγή

Στόχος: 10-15 σελίδες.

Ενότητες:
- Διατύπωση προβλήματος.
  - Ο κτιριακός τομέας στο ενεργειακό και κλιματικό πρόβλημα.
  - Παλαιότητα και ενεργειακή ανεπάρκεια του κτιριακού αποθέματος.
  - Ευρωπαϊκό θεσμικό πλαίσιο για την ενεργειακή απόδοση κτιρίων.
  - Η ελληνική πραγματικότητα και τα προγράμματα ενεργειακής αναβάθμισης.
  - Χρηματοδότηση ενεργειακών ανακαινίσεων και εμπόδια υλοποίησης.
  - Κατακερματισμός πληροφορίας και ανάγκη υποστήριξης αποφάσεων.
- Σκοπός της διπλωματικής και προτεινόμενη λύση.
  - Από την ετερογενή πληροφορία στη δομημένη γνώση.
  - Μεγάλα γλωσσικά μοντέλα ως εργαλείο εξαγωγής και τυποποίησης πληροφορίας.
  - Ερευνητικό κενό, πεδίο εφαρμογής και συμβολή της εργασίας.
- Οργάνωση Τόμου.

Σημείωση πηγών: στην εισαγωγή προτιμώνται επίσημες/θεσμικές διαδικτυακές
πηγές, ενώ η ερευνητική βιβλιογραφία των LLMs, του web scraping και της
αξιοπιστίας αναπτύσσεται κυρίως στο Κεφάλαιο 2.

Σχήματα:
- Σχήμα 1.1: Ρόλος κτιριακού τομέα στην ενεργειακή κατανάλωση.
- Σχήμα 1.2: Ευρωπαϊκό θεσμικό πλαίσιο / timeline.
- Σχήμα 1.3: Κατακερματισμός πληροφορίας.
- Σχήμα 1.4: Εννοιολογικό pipeline της εργασίας.

Πίνακες:
- Πίνακας 1.1: Κατηγορίες χρηματοδοτικών εργαλείων.
- Πίνακας 1.2: Πρόβλημα, τεχνική ανάγκη, συμβολή.

## 2. Θεωρητικό Υπόβαθρο

Στόχος: 8-12 σελίδες, δηλαδή λίγο πιο σύντομο από την Εισαγωγή.

Ενότητες:
- Ενεργειακή απόδοση κτιρίων και βασικές έννοιες.
- Ενεργειακές αναβαθμίσεις κατοικιών.
- Πιστοποιητικό Ενεργειακής Απόδοσης και ενεργειακές κατηγορίες.
- Χρηματοδοτικά εργαλεία ενεργειακής αποδοτικότητας.
- Δημόσια προγράμματα στην Ελλάδα.
- Τραπεζικά πράσινα προϊόντα και επιδοτούμενα δάνεια.
- ESCOs και συμβάσεις ενεργειακής απόδοσης.
- Επεξεργασία φυσικής γλώσσας.
- Transformers και μεγάλα γλωσσικά μοντέλα.
- Prompt engineering, structured extraction και JSON schemas.
- Web scraping και συλλογή διαδικτυακού περιεχομένου.
- Αξιοπιστία LLMs, hallucinations και μηχανισμοί επαλήθευσης.
- Υπολογιστικό κόστος και περιβαλλοντικό αποτύπωμα LLMs.

Προτεινόμενα σχήματα:
- Ροή ενεργειακής αναβάθμισης κατοικίας.
- Ταξινόμηση χρηματοδοτικών εργαλείων.
- Βασική αρχιτεκτονική Transformer σε υψηλό επίπεδο.

Σημείωση πηγών: στο Θεωρητικό Υπόβαθρο η έμφαση μεταφέρεται από τις επίσημες
θεσμικές ιστοσελίδες προς την ερευνητική και τεχνική βιβλιογραφία. Οι θεσμικές
πηγές χρησιμοποιούνται μόνο όπου χρειάζεται ορισμός ή πλαίσιο, ενώ οι έννοιες
LLMs, RAG, prompting, scraping, structured extraction, αξιοπιστία και
υπολογιστικό κόστος τεκμηριώνονται κυρίως με βιβλία, άρθρα και τεχνικές
προδιαγραφές.

## 3. Μεθοδολογία

Στόχος: 8-12 σελίδες.

Ενότητες:
- Σκοπός και ερευνητικός σχεδιασμός.
- Πεδίο εφαρμογής και απαιτήσεις.
  - Απαιτήσεις της μεθοδολογίας.
  - Πεδίο εφαρμογής και μονάδα ανάλυσης.
- Πηγές, αρχιτεκτονική και ροές εργασίας.
  - Επιλογή και κατηγοριοποίηση πηγών.
  - Συνολική αρχιτεκτονική της προτεινόμενης προσέγγισης.
  - Ρόλοι χρηστών και ροές εργασίας.
- Διαδικασία συλλογής, συνάφειας και εξαγωγής.
  - Συλλογή και προεπεξεργασία περιεχομένου.
  - Απόφαση συνάφειας.
  - Εξαγωγή και τυποποίηση δεδομένων.
  - Σχεδιασμός προτροπών και διαχείριση αβεβαιότητας.
- Έλεγχος ποιότητας και επικαιροποίηση.
  - Έλεγχος ποιότητας και ανθρώπινη εποπτεία.
  - Επικαιροποίηση και διαχείριση εκδόσεων δεδομένων.
- Μεθοδολογία αξιολόγησης.
- Περιορισμοί και σύνδεση με την υλοποίηση.
  - Περιορισμοί μεθοδολογίας.
  - Σύνδεση με την υλοποίηση.

Προτεινόμενα σχήματα:
- Πλήρης αρχιτεκτονική συστήματος.
- Data flow από URL έως εγκεκριμένο πρόγραμμα.
- Validation loop.

Σχήματα:
- Σχήμα 3.1: Μεθοδολογική αρχιτεκτονική της προτεινόμενης προσέγγισης.

Πίνακες:
- Πίνακας 3.1: Βασικές απαιτήσεις που καθοδηγούν τη μεθοδολογία.
- Πίνακας 3.2: Κατηγορίες πηγών και ρόλος τους στη μεθοδολογία.
- Πίνακας 3.3: Ομάδες πεδίων του σχήματος δεδομένων.
- Πίνακας 3.4: Στάδια ελέγχου ποιότητας.
- Πίνακας 3.5: Άξονες αξιολόγησης.

Σημείωση πηγών: η μεθοδολογία τεκμηριώνει τις γενικές τεχνικές και
επιστημονικές αρχές με βιβλιογραφία, όπως ποιότητα δεδομένων, HTML parsing,
JSON schema, prompt engineering, RAG/grounding, hallucinations και risk
management. Οι αποφάσεις που αφορούν τη συγκεκριμένη ροή της εργασίας
τεκμηριώνονται από την ίδια την αρχιτεκτονική και αναλύονται τεχνικά στο
Κεφάλαιο 4.

## 4. Υλοποίηση

Στόχος: 20-30 σελίδες.

Ενότητες:
- Τεχνολογική στοίβα.
- Δομή repository.
- VA1: επιλογή/αξιολόγηση URL.
- VA3: scraping και μετατροπή σε template.
- VA4: product discovery και LLM classification.
- JSON schema χρηματοδοτικού προγράμματος.
- Prompt templates.
- Μοντέλα που εξετάστηκαν.
- Παράμετροι μοντέλων.
- Logging και αποθήκευση αποτελεσμάτων.
- Validation scripts.
- Διαχείριση σφαλμάτων.
- Παραδείγματα εξαγόμενων JSON.

Προτεινόμενα σχήματα:
- Class/module diagram.
- Sequence diagram για επεξεργασία URL.
- Παράδειγμα JSON schema.

## 5. Αποτελέσματα και Αξιολόγηση

Στόχος: 15-25 σελίδες.

Ενότητες:
- Περιγραφή συνόλου αξιολόγησης.
- Πηγές και URLs που χρησιμοποιήθηκαν.
- Μετρικές αξιολόγησης classification.
- Μετρικές αξιολόγησης extraction.
- Έλεγχος κάλυψης πεδίων.
- Έλεγχος συνέπειας Q&A.
- Semantic metrics.
- Ανάλυση αποτυχιών.
- Σύγκριση μοντέλων ή ρυθμίσεων.
- Συζήτηση αποτελεσμάτων.

Προτεινόμενα γραφήματα:
- Coverage ανά πρόγραμμα.
- Accuracy/consistency ανά ερώτηση.
- Confidence distribution.
- Πλήθος missing fields.
- Σύγκριση εκδόσεων pipeline.

## 6. Διαδικτυακή Εφαρμογή

Στόχος: 10-16 σελίδες.

Ενότητες:
- Σκοπός εφαρμογής.
- Ρόλοι admin και user.
- Backend endpoints.
- Frontend views.
- Ροή διαχειριστή: crawl, review, edit, approve.
- Ροή χρήστη: επιλογή προγράμματος, ανάγνωση στοιχείων, ερωτήσεις.
- Παραδείγματα χρήσης.
- Περιορισμοί και θέματα ασφάλειας.
- Μελλοντική ενσωμάτωση σε παραγωγικό περιβάλλον.

Προτεινόμενα σχήματα:
- UI/data flow.
- Admin workflow.
- User workflow.
- Screenshots εφαρμογής.

## 7. Συμπεράσματα και Μελλοντική Εργασία

Στόχος: 6-10 σελίδες.

Ενότητες:
- Σύνοψη εργασίας.
- Βασικά ευρήματα.
- Συνεισφορά στο πρόβλημα κατακερματισμού πληροφορίας.
- Τεχνικοί περιορισμοί.
- Περιορισμοί αξιολόγησης.
- Μελλοντικές βελτιώσεις:
  - περισσότερες πηγές,
  - αυτόματη ανίχνευση αλλαγών,
  - καλύτερο validation,
  - RAG με τεκμηριωμένες απαντήσεις,
  - παραγωγική βάση δεδομένων,
  - αξιολόγηση με ειδικούς/μηχανικούς.

## Παραρτήματα

Πιθανά παραρτήματα:
- Prompt templates.
- Ενδιάμεσα finetunings ή δοκιμές μοντέλων.
- Πλήρες JSON schema.
- Ενδεικτικά extracted JSON αρχεία.
- Πίνακες URLs και πηγών.
- Πρόσθετα αποτελέσματα αξιολόγησης.
- Οδηγίες εκτέλεσης εφαρμογής.
