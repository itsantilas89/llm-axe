# Διπλωματική Εργασία - Φάκελος Συγγραφής

Αυτός ο φάκελος είναι το working draft της διπλωματικής σε LaTeX/Overleaf.
Ο στόχος είναι να γράφεται το κείμενο κατευθείαν σε μορφή που μπορεί να
μεταφερθεί στο επίσημο template της ΣΗΜΜΥ ΕΜΠ.

## Προτεινόμενη ροή εργασίας

1. Γράφουμε κάθε κεφάλαιο σε ξεχωριστό αρχείο μέσα στο `chapters/`.
2. Κρατάμε όλες τις βιβλιογραφικές εγγραφές στο `references.bib`.
3. Φτιάχνουμε τα σχήματα ως TikZ/LaTeX όπου γίνεται, ώστε να είναι καθαρά,
   ελληνικά, αριθμημένα και επεξεργάσιμα.
4. Όταν ολοκληρωθεί το υλικό, το μεταφέρουμε στο επίσημο NTUA ECE template ή
   αντικαθιστούμε το απλό `main.tex` με το επίσημο template.

## Αρχεία

- `main.tex`: προσωρινό LaTeX entry point για compile.
- `chapters/01_introduction.tex`: αναλυτική εισαγωγή, στόχος 10-15 σελίδες.
- `chapters/02_theoretical_background.tex`: θεωρητικό υπόβαθρο, λίγο πιο
  σύντομο από την εισαγωγή.
- `chapters/03_methodology.tex`: μεθοδολογία, αρχιτεκτονική ροή,
  ποιότητα δεδομένων, ανθρώπινη εποπτεία και αξιολόγηση.
- `references.bib`: βιβλιογραφία σε BibTeX/Biber, με όλες τις εγγραφές που
  χρησιμοποιούνται στα κεφάλαια.
- `figures/*.tex`: επεξεργάσιμα σχήματα.
- `source_log.md`: πηγές, δικαιώματα χρήσης και σημειώσεις αξιοπιστίας.
- `preview/full_draft_with_figures.html`: ενιαίο HTML preview του μέχρι τώρα
  προσχεδίου.
- `preview/full_draft_with_figures.pdf`: γρήγορο PDF preview που παράγεται
  από το HTML για ανάγνωση. Δεν αντικαθιστά το τελικό XeLaTeX/Overleaf PDF.

## Σημείωση μορφοποίησης

Η τελική κατάθεση γίνεται ως PDF και πρέπει να ακολουθήσει τον Οδηγό
Συγγραφής της Βιβλιοθήκης ΣΗΜΜΥ ΕΜΠ. Το παρόν scaffold είναι για συγγραφή
και επιμέλεια περιεχομένου.
